# Disaster Relief & Community Resilience Platform

A modern, full-stack ASP.NET Core MVC web application built to streamline disaster response coordination, volunteer registration, and real-time contribution tracking. 

## Overview
During crisis situations, rapid response and efficient resource allocation are vital. This platform provides an intuitive, high-performance interface where community members can register as specialized volunteers (such as medical personnel, logisticians, or engineers) and log contributions (financial support, medical supplies, or food parcels) to support ongoing relief operations.

## Key Features
* **Specialized Volunteer Registration**: Allows responders to submit their contact details and specialized skills for targeted deployment.
* **Real-Time Impact Tracker & Contribution Logging**: Tracks funds raised and active volunteers while enabling donors to log contributions directly into the database.
* **Responsive Editorial UI**: Designed with Tailwind CSS for a clean, accessible, and modern user experience across mobile and desktop devices.
* **Robust Backend Architecture**: Built on clean MVC patterns utilizing Entity Framework Core and SQL Server for reliable relational data management.

## Tech Stack
* **Framework**: ASP.NET Core 9.0 (MVC)
* **Database & ORM**: SQL Server, Entity Framework Core (Code-First Migrations)
* **Frontend**: Tailwind CSS, HTML5, Razor Views
* **Version Control**: Git & GitHub
